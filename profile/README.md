### Norma by Quality Clouds: any Git repository

Norma reviews code the way a senior engineer would, on every repository and every team, in two layers:

- **Findings.** An AI review that asks the same questions on every repository: does the database have the indexes it needs, does the app keep a client-server split, where will it slow down under load. These are the questions someone building an app on Lovable or a similar tool usually can't answer alone.
- **Checks.** Rule-based and deterministic: the same code gets the same verdict every time. A hard-coded secret, a missing security header, a dependency your policy forbids. Every check leaves an audit record.

Norma detects the stack automatically: JavaScript, TypeScript, Python, PHP and Dart (including Flutter), with rulesets for React, Node, Vite, FastAPI, SQLAlchemy, Supabase and Adobe Magento. Permanent free tier.

Where it runs:

- Inside the agent loop, through the [Norma MCP server](https://github.com/qualityclouds/norma-mcp), in Claude Code, Cursor, Windsurf, Lovable, Replit, Codex and any MCP client
- On every pull request, through the [Norma GitHub App](https://github.com/apps/norma-by-quality-clouds), which posts a review comment and asks for a single permission
- In your editor, with the [VS Code extension](https://marketplace.visualstudio.com/items?itemName=qualityclouds.norma-for-vscode), also on Cursor and VSCodium via Open VSX
